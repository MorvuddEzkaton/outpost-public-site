Завантажити OutPOSt v0.24.42 для Windows

Актуальна Windows-збірка OutPOSt v0.24.42 та окрема Бухгалтерія v1.0.2 доступні нижче з точними SHA-256. Перед оновленням OutPOSt зробіть резервну копію бази; обидва інсталятори поки не мають Authenticode-підпису.

Windows 10/11.NET Framework 4.8x86Офіційні файли outpost.com.ua
Перед встановленням

SmartScreen можливий

Інсталятори поки не мають платного Authenticode-підпису. Завантажуйте файли лише з офіційного домену та звіряйте контрольну суму, якщо Windows показує попередження.

Що змінилося у версіях
Для УБД — безкоштовно. За чинним посвідченням УБД одна повна ліцензія на один робочий ПК надається безкоштовно.
ПОТОЧНІ ЗБІРКИ

Два продукти — два окремі інсталятори.

Актуальний OutPOSt призначений для магазину. Версія v0.24.42 пройшла автоматизовані перевірки, але перед робочим впровадженням потребує приймання на копії бази й цільовому ПК. Окрема Бухгалтерія v1.0.2 доступна для Windows; повторне Windows RC приймання пройдено. Обидва інсталятори поки без цифрового підпису.

01 · ВСТАНОВЛЕННЯ

Короткий порядок дій.

Основні дані магазину зберігаються окремо від Program Files. Перед переходом на v0.24.42 обов’язково створіть резервну копію: схема бази оновлюється до 0.21.12, а для повернення на старішу програму потрібна відповідна передоновлювальна копія бази.

1Завантажити

Використати лише офіційний файл outpost.com.ua.

2Перевірити

За потреби звірити SHA‑256 інсталятора.

3Встановити

Запустити Setup і пройти стандартний майстер Windows.

4Запустити

OutPOSt використовує окрему папку для робочих даних.

02 · ПЕРЕВІРКА ФАЙЛУ

SHA‑256 — точна контрольна сума.

Якщо файл був змінений хоча б на один байт, його SHA‑256 буде іншим. Це допомагає відрізнити офіційний інсталятор від пошкодженої або сторонньої копії.

OutPOSt v0.24.42

SHA‑256: B44BA8F936AD863493F1DD5B5E114F9AB86D35324DD982AFC1F1B4D975384E66

Accounting v1.0.2

SHA‑256: 372B1A6B97A53FCF5656658B53E205F4B8D97ECE6EEDA85BD391A76B934F495F

Як перевірити SHA‑256 у Windows PowerShell

Get-FileHash .\OutPOSt-Setup-v0.24.42.exe -Algorithm SHA256

Значення Hash має повністю збігатися з опублікованою сумою.

Що робити, якщо сума не збігається

Не запускайте файл. Видаліть його та завантажте інсталятор повторно з офіційної сторінки.

03 · ОНОВЛЕННЯ

Програма окремо. Дані магазину окремо.

OutPOSt розділяє програмні файли й робочу SQLite-базу. Це зменшує ризик втрати даних під час звичайного встановлення нової версії.

Перед оновленням

Зробіть резервну копію

Перед v0.24.42 це обов’язковий крок: збережіть копію бази до запуску інсталятора.

Під час оновлення

Не очищайте папку даних

Звичайний installer оновлює програму; робоча база зберігається окремо.

Після оновлення

Перевірте запуск

Переконайтеся, що версія змінилася, база відкрилася й ключові операції доступні.

04 · ПИТАННЯ

Перед завантаженням.

Якщо інсталятор не запускається або Windows показує незрозуміле попередження, краще звірити файл і звернутися в підтримку, ніж шукати сторонню копію програми.

Чому Windows показує SmartScreen?

Інсталятор поки не має платного цифрового підпису Authenticode. Це не замінює перевірку походження файлу; завантажуйте лише з outpost.com.ua та звіряйте SHA‑256.

Чи потрібен Інтернет для роботи OutPOSt?

Основний облік і продажі працюють локально. Інтернет потрібен для першої активації 7-денного пробного доступу й окремих онлайн-сервісів; після активації в межах строку можна працювати офлайн.

Чи видалиться база при оновленні?

Робочі дані зберігаються окремо від програмних файлів, але v0.24.42 використовує схему 0.21.12. Перед оновленням зробіть резервну копію; для відкату на старішу програму відновлюйте і відповідну стару базу.

Яку версію Бухгалтерії ставити?

Завантажуйте Бухгалтерію v1.0.2. Інсталятор пройшов Windows RC, але ще не має Authenticode-підпису. Для роботи з реальними даними спочатку створіть резервну копію, звірте SHA-256 та виконайте контрольну перевірку.

ПРОБНИЙ ДОСТУП

7 днів для перевірки OutPOSt на своєму ПК

7-денний пробний доступ активується через Налаштування → Ліцензія → Активувати пробний доступ. Перша активація потребує інтернету; після неї можна працювати офлайн. Сім діб рахуються від першої активації цього ПК; перевстановлення не поновлює строк.

Робота в межах ваших прав

Перевіряйте продажі, закупівлі й доступні модулі. Права працівників зберігаються, вимкнені модулі не вмикаються автоматично. Тестові обмеження Native ПРРО та еАкцизу залишаються чинними.

Дані залишаються вашими

Після завершення пробного доступу нові бізнес-операції недоступні до активації ліцензії. Дані не видаляються: залишаються вхід, перегляд, історія, повторний друк, експорт і резервні копії; уже відкриту локальну зміну можна закрити. Чинні безстрокові ліцензії працюють як раніше.

Безстрокова ліцензія

Після перевірки активуйте повну ліцензію для цього ПК. Ціна, умови підтримки й пільга для УБД не змінилися.
