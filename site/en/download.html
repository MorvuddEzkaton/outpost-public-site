Install and verify your download

  1. Download the exact official file or use the Microsoft Store listing.
  2. Compare the SHA-256 with the checksum for that exact file; the downloader and full package have different hashes.
  3. Run the verified installer and follow the Windows setup wizard.
  4. Start OutPOSt. Its local working data is stored separately from Program Files.

PowerShell example for the universal Retail downloader:

Get-FileHash .\OutPOSt-Setup.exe -Algorithm SHA256

If the checksum does not match, do not run the file. Download it again from the official source. A matching checksum alone does not establish publisher signature or safety.

Update without losing your shop data

Keep a verified backup before installing an update. Close OutPOSt normally and do not delete its data folder. After installation, confirm the version, database and key workflows on the target PC. Check current version-specific migration guidance and release evidence on the Ukrainian download page; automated tests are not a substitute for acceptance on your own database copy.

Website Retail uses its signed update-package mechanism; this does not mean the standalone Windows installer has an Authenticode signature. Store updates are managed by the Store.

Download and installation questions

Why does Windows show SmartScreen?

The website installers are not Authenticode-signed. Download only from the official domain and compare the SHA-256 published for the exact file. A checksum is not a digital signature.

Do I need internet to use OutPOSt?

Core sales and inventory work locally. Full Retail needs internet for first trial activation and optional online services. The universal Retail downloader needs internet to retrieve the current package. Lite needs no account or trial activation.

Will updating delete my database?

Shop data is stored separately from program files. Before updating, create and verify a backup. For rollback to an older application, restore its corresponding compatible database; do not assume a newer database works with an older build.

How do I update from an older version?

Read the current release notes and installation instructions on the Ukrainian download page. Close OutPOSt normally before using the official Setup. Some older versions may wait for a full backup before upgrading; follow the version-specific guidance rather than bypassing safety checks.

How do I sign in and activate my license?

For Retail, open Settings → License and enter your account password or email code within the Windows application. An already issued license for that PC and available online services connect automatically. Signing out does not delete the local license or shop data.

Which Accounting build should I install?

Use the current separate Accounting pre-release shown on the official Ukrainian download page. Review its Windows RC evidence and checksum; real-data acceptance is separate. Create a backup and test on a copy before using it operationally.
